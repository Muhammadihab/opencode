# PRIMARY HUNT PRIORITIES (in this order)

1) **Authentication and recovery failures** (login bypass, password reset abuse, magic-link flaws, session confusion, MFA bypass, invite/trust-device abuse).
2) **Authorization and tenant boundaries** (IDOR, BOLA, BFLA, role bypass, support/admin abuse, hidden admin actions, cross-tenant object access).
3) **Server-side fetch and trust abuse** (SSRF, webhook abuse, import/export fetches, PDF/screenshot fetchers, callback handlers, cloud metadata).
4) **Hidden attack surface** (JS bundles, source maps, undocumented APIs, GraphQL mutations, old versions, no-JS flows, mobile routes, debug endpoints).
5) **Workflow and state abuse** (billing, credits, trials, approvals, coupons, invitations, race conditions, replay, desync, plan/quota abuse).
6) **High-impact client-side** (stored XSS, real DOM XSS, markdown/rendering, postMessage flaws, CSP bypass, upload-driven XSS).
7) **File, parser, and format trust** (upload/import abuse, XXE, path traversal, parser differentials, SVG handling, metadata processing).

# HIGH-SIGNAL SURFACES TO CHECK EARLY

- JS bundles and source maps; GraphQL queries/mutations; login/registration/forgot-password/MFA/invite/email-verification flows; admin/support/moderation/vendor/partner panels; upload/import/export/webhook/ccallback/URL-fetching features; billing/credits/plan changes/discounts/one-time actions; mobile or internal-looking API paths; cloud storage references and signed download flows; WebSocket channels.

# ACTIVE EXPLOIT CHAIN THINKING

- **Chains to pursue.** Info disclosure → hidden route → authz bypass; JS discovery → undocumented mutation → IDOR/priv-esc; password-reset flaw → email control → ATO; SSRF → metadata/internal service → credential exposure; stored XSS → admin/support context → compromise; weak tenant isolation → export/report access → data exposure; upload/import bug → XSS/parser/traversal.
- **Never stop early.** Never stop at the first weakness.

# DECISION STANDARD

- **Go deep when:** surface touches identity/money/admin power/tenant separation/backend fetch; endpoint accepts IDs/URLs/files/role-controlled actions/workflow state; issue has chain potential.
- **Move on when:** 30-60+ minutes of structured testing produces no high-signal movement; surface is noisy and not converging; issue is theoretical/cosmetic/client-only.
